# AI 接口文档

本文档面向前端联调，描述当前已开放的 AI 草稿和 AI 调用记录接口。模块实现、限流配置与排查方式分别见 [AI 调用记录模块文档](../ai-call-log-module.md) 和 [Redis AI 限流模块文档](../redis-rate-limit-module.md)。

## 基础约定

- Base URL：`http://localhost:8123/api`
- 除登录、注册等公开接口外，本文档中的接口均需要已登录用户。
- 认证请求头：`Authorization: Bearer <JWT>`。后端也兼容直接传入 JWT，但前端统一使用 `Bearer` 前缀。
- 时间字段使用 ISO-8601 本地日期时间，例如 `2026-07-11T10:30:00`；日期字段使用 `yyyy-MM-dd`。
- 数据按当前登录用户隔离，不能读取或操作其他用户的草稿、项目或调用记录。

所有接口均使用统一响应结构：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

`code = 0` 表示业务成功。项目的业务异常可能仍以 HTTP `200 OK` 返回，因此客户端必须优先根据响应体中的 `code` 判断结果，不能只依据 HTTP 状态码。

## 通用错误码

| code | 含义 | 客户端处理建议 |
|---:|---|---|
| `40000` | 请求参数错误 | 展示参数校验提示，不重复提交。 |
| `40100` | 未登录或登录已失效 | 清理登录态并跳转登录页。 |
| `40300` | 禁止访问 | 展示无权限提示。 |
| `40400` | 请求的数据不存在 | 刷新当前页面或返回上一页。 |
| `42900` | AI 请求过于频繁 | 提示用户稍后重试；不要自动重试或连续创建草稿。 |
| `30001` | AI 服务暂时不可用 | 保留用户输入，允许用户稍后重新发起预览。 |
| `30002` | AI 服务响应超时 | 提示“结果可能已生成”，优先查询已返回的草稿或调用记录，避免盲目重复请求。 |
| `30003` | AI 返回结果格式异常 | 提示生成失败，保留用户输入后重新发起预览。 |
| `30004` | AI 服务配置异常 | 展示服务配置异常提示，不对用户自动重试。 |
| `50001` | 操作失败 | 重新拉取服务端状态后，再决定是否允许用户继续操作。 |

## AI 限流约定

`POST /ai/breakdown/preview` 属于 `task-breakdown` 场景，默认限制为同一用户 60 秒内最多 3 次。限流失败返回业务码 `42900`，当前响应中不包含 `Retry-After`。

草稿详情、确认和取消都是本地业务操作，不会再次调用大模型，也不受该 AI 限流规则限制。
