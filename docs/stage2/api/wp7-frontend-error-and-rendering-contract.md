# WP7 前端错误与安全渲染合同

状态：`FROZEN`

## TraceId

前端只从响应 Header `X-Trace-Id` 获取 TraceId。Axios Header 名按大小写不敏感处理；值必须去除首尾空白且不超过 128 个字符，否则视为缺失。前端不从响应正文、错误消息或 URL 推断 TraceId。

`ApiRequestError` 内部增加可空 `traceId` 字段。该变化不修改服务端响应结构。

## AI 错误动作

| 错误码 | 动作 |
|---|---|
| 30001、30002、30003、30010、42900 | 保留上下文，允许用户手动重试 |
| 30004 | 不建议重试，提示联系管理员 |
| 30005～30008 | 刷新草稿或操作的服务端事实 |
| 30009 | 不重试，提示功能已关闭 |
| 30011 | 不重发原请求，提示编辑输入 |

401/403 和普通业务错误继续使用现有全局行为。前端不自动重试；后端仍是唯一的模型 fallback 执行者。

## 渲染边界

- AI 自由文本使用 `SafeAiText` 组件或等价 Vue 文本插值。
- 换行通过 CSS `white-space: pre-wrap` 保留。
- HTML、事件属性、脚本和伪 Markdown 链接不解析、不执行、不转为链接。
- 静态门禁扫描 AI 相关视图、组件和组合式函数，阻止危险 DOM API。
