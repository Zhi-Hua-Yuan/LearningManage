# PR7 前端任务权限与团队上下文合同

状态：`FROZEN（WP7-A 已合并）`

日期：2026-08-31

## 1. 安全原则

- 后端 `PermissionService` 是授权权威；
- 前端能力值只是界面提示，不能作为写入授权证明；
- 任务操作不得从团队角色重新推导，必须使用任务 VO 中的 capability；
- capability 缺失或结构非法时全部动作默认关闭；
- 每次写操作后使用服务端最新任务重新计算界面状态。

## 2. capability 映射

| capability | 允许的界面操作 | 不包含 |
|---|---|---|
| `canEditContent` | 标题、描述、截止日期 | 优先级、里程碑、负责人、删除 |
| `canChangeStatus` | 待办/完成状态、完成质量 | 普通更新接口修改状态 |
| `canReorganize` | 优先级、里程碑 | 标题、负责人、删除 |
| `canAssign` | 分配、转派、解除负责人 | 普通任务更新修改负责人 |
| `canDelete` | 删除任务 | 项目或里程碑删除 |

实现要求：

- 显示/隐藏或禁用方式由组件可用性决定，但禁用控件必须有可理解提示；
- 前端不得仅通过 CSS 隐藏仍可触发的写操作；
- 共享方法不得把五项 capability 合并成模糊的 `canEdit`；
- 任何 `40300` 触发任务重新读取，而不是本地猜测新的 capability。

## 3. 新建任务入口

项目 VO 当前没有项目 capability，因此只对“新建任务入口”使用团队上下文中的当前角色：

| 项目类型 | 当前上下文 | 快速创建 |
|---|---|---|
| 个人项目 | 项目所有者 | 显示 |
| 团队项目 | OWNER / ADMIN | 显示，并允许选择有效成员或未分配 |
| 团队项目 | MEMBER | 隐藏或禁用并提示无创建权限 |
| 未知/失权项目 | 无可信上下文 | 不显示 |

后端仍在 `/task/add` 重新校验。团队角色不得用于推导已有任务的编辑、状态、转派和删除能力。

## 4. 团队导航与加载

侧边栏层级冻结为：

```text
个人清单
  个人项目

团队
  团队名称（当前角色）
    团队项目
```

加载顺序：

```text
当前用户
→ 个人项目 + 我的团队
→ 展开团队时加载该团队项目
→ 打开负责人选择器时加载该团队成员
```

约束：

- 不在应用启动时为所有团队并发拉取项目和成员；
- 团队 ID 只作为查询上下文，不作为授权证明；
- 团队项目路由保留 `projectId` 并附加 `teamId`；
- 进入路由后仍以接口返回结果确认项目和当前成员关系；
- 失权、被移除或项目删除后清理当前团队上下文并回到可访问页面。

## 5. 负责人选择

- 个人项目只展示当前用户，不提供其他成员；
- 团队项目选项来自最新 `/team/{teamId}/members`；
- 团队负责人选项包含 `userId`、`username`、`role`，提交只发送 `userId`；
- 团队项目允许明确选择“未分配”；
- 已退出成员不继续作为选项；
- 当前负责人不在成员列表时仍展示任务事实，但标记“已不在团队”，转派时不能再次选中；
- 提交期间冻结选择器，避免重复发送不同请求。

## 6. 负责人历史展示

| action | 文案 |
|---|---|
| `INITIAL_ASSIGN` | 初始分配 |
| `ASSIGN` | 分配负责人 |
| `REASSIGN` | 转派负责人 |
| `UNASSIGN` | 解除分配 |
| `MEMBER_LEFT` | 成员退出，自动解除 |
| `MEMBER_REMOVED` | 成员被移除，自动解除 |

用户摘要降级规则：

- 对象为 `null`：显示“未分配”；
- `userId` 存在而 `username` 为空：显示“用户 #ID”或“已删除用户”；
- 不请求或展示账号、角色、删除标记、密码等字段；
- `reason` 按纯文本渲染，禁止 `v-html`。

## 7. 前端类型和组件边界

建议：

```text
TaskAssigneePicker.vue       只负责成员选项和未分配选择
TaskAssignmentDialog.vue     负责 expectedAssignee、reason 和提交状态
TaskAssignmentHistory.vue    负责分页和安全展示
taskCapabilities.ts          负责安全默认值和控件映射
collaboration store          负责当前用户、团队、项目、成员的内存状态
```

页面容器负责组合流程，不在多个页面中复制 capability 判定或成员加载逻辑。
