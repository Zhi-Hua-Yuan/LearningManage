## 7. 安全和工程缺口

- `JwtUtils` 存在硬编码 JWT 密钥。
- 开发、测试配置存在固定数据库口令。
- AI 配置存在默认值或占位配置。
- 当前没有 Gitleaks 可执行文件。
- 后端和前端都没有 GitHub Actions 工作流。
- 前端没有自动化测试脚本。
- Docker CLI 可用，但 Docker Desktop Linux daemon 在执行时不可达，因此 Docker 构建未执行。

本报告未保存任何真实密码、Token、API Key、用户密码哈希或 AI 正文。
