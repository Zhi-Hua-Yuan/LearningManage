## 使用规则

- `ACCEPTED_RISK` 必须有明确责任人、缓解措施和重新评审触发条件。
- `DEFERRED` 必须有目标阶段，不能写成“以后处理”。
- `NOT_APPLICABLE` 只表示当前没有调用方或不在当前部署边界，不代表永久安全。
- 本表不保存密码、Token、JWT、API Key、数据库备份或业务数据。
- D4 最终封存时应计算本文件 SHA-256，并将摘要写入最终候选 Manifest 或 Release 附件。
